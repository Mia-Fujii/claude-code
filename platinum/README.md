# プラチナプログラム 契約管理（Google Apps Script）

新規契約・更新のたびに必要な作業を、管理用スプレッドシートに1行入力するだけで自動化します。

| やること | 自動で行う内容 |
|---|---|
| メンバーリスト | 「最新版メンバーリスト」の一番下に追加します。更新の方は元の行を削除し、過去の契約期間をI列以降（新しい順）に残します |
| 分割支払い | 「分割支払い」シートに期日を入れて1行追加します（一括の方も追加します） |
| 税理士さん用 | 「税理士共有用」の「プラチナ」タブに1行追加します（併用払いは総額で1行） |
| 覚書 | 分割の方だけ、雛形から覚書を作ってPDFにします（GMOサインへのアップロードは手動です） |
| メール | 新規/更新 × 一括/分割 の案内メールをGmailの**下書き**に作ります |
| 期日の通知 | 毎朝チェックし、2回目の期日の14日前になったらチャットワークに通知して、支払い案内メールの下書きを作ります |

---

## はじめの設定（1回だけ）

**すべて事務局アカウント（shinealight の Gmail）にログインした状態で行ってください。**
Gmail の下書きは、スクリプトを実行したアカウントに作られます。

### 1. 空のスプレッドシートを作る
1. Google ドライブで「新規 → Google スプレッドシート」を選びます
2. 名前を「プラチナ契約管理」などにします

### 2. コードを貼り付ける
1. スプレッドシートのメニューから「拡張機能 → Apps Script」を開きます
2. 最初から入っている `function myFunction() {}` をすべて消して、`Code.gs` の中身を全部貼り付けます
3. 左の ⚙️「プロジェクトの設定」を開き、**タイムゾーンを「(GMT+09:00) 日本標準時 - 東京」**にします
4. 💾 で保存します

### 3. 初期設定を実行する
1. スプレッドシートのタブに戻って、ページを再読み込みします
2. メニューに「**プラチナ管理**」が出てくるので、「⚙️ 初期設定（最初に1回）」を押します
3. 「承認が必要です」と出たら、事務局アカウントを選んで「許可」を押します
   - 「このアプリは Google で確認されていません」と出た場合は、「詳細」→「（安全でないページ）に移動」→「許可」の順に進みます。ご自身で作ったスクリプトなので問題ありません
4. もう一度「初期設定」を押します（承認だけで止まることがあるため）

初期設定を実行すると、次のものが自動で作られます。

```
📁 プラチナ契約対応
   ├ 📁 覚書                  … 作成した覚書とPDFがここに保存されます
   └ 📁 テンプレート
        ├ 【雛形】プラチナプログラム 覚書
        ├ 【メール】新規_一括
        ├ 【メール】新規_分割
        ├ 【メール】更新_一括
        ├ 【メール】更新_分割
        └ 【メール】2回目以降の支払い案内
```

あわせて、スプレッドシートに「契約入力」「支払予定」「料金マスタ」「設定」のシートが作られ、毎朝9時ごろのチェックも設定されます。

### 4. チャットワーク
1. 「設定」シートの **チャットワーク_ルームID** に、通知を受け取るルームのIDを入れます
   （ルームを開いたときのURL `…#!rid123456789` の数字の部分です）
2. メニューの「💬 チャットワークのトークンを登録」を押して、APIトークンを貼り付けます
   （チャットワーク右上のメニュー →「サービス連携」→「APIトークン」で確認できます）
3. 登録するとテストメッセージが届きます

> 通知は**自分のトークンで送っても未読（未読①）が付く**ように送ります（チャットワークAPIの `self_unread`）。

## テストしてから本番に切り替える

1. メニューの「🧪 テスト用コピーに切り替える」を押します
   → メンバーリストと税理士シートのコピーが作られ、以後はコピーのほうに書き込まれます（本物のシートには書き込まれません）
2. 「契約入力」にテスト用の行を入れて処理します（宛先は自分のメールアドレスにすると安心です）
3. 確認が終わったら、次の順で本番に戻します
   - 「契約入力」と「支払予定」のテスト行を削除します
   - テストで作られたGmailの下書きを削除します
   - メニューの「🏁 本番シートに戻す」を押します

## ふだんの使い方

### 新規・更新があったとき
1. 「契約入力」に1行入力します

   | 列 | 入れる内容 |
   |---|---|
   | 新規/更新・個別コンサル | プルダウンから選びます |
   | 氏名・メールアドレス | メンバーリストとはメールアドレスで照合するので、正しく入れてください |
   | 契約日 | **更新の方は空欄でOK**です。最新版メンバーリストの契約満了日の翌日が自動で入ります。契約が切れたあとで更新した場合など、別の日にしたいときだけ入力します |
   | 手続き期限（1回目の期日） | メールの「〇月〇日（〇）までに」に入る日付です。**更新の方は空欄なら契約日の前日**になります（過ぎている場合は入力してください）。分割の場合は、この日から毎月（2分割は半年ごと）の期日になります |
   | 支払回数 | 一括は **1**、12分割は **12** |
   | 支払方法 | 銀行振込 / PayPal / スクエア / mosh / 併用 |
   | 併用の内訳 | 併用のときだけ入れます。例：`銀行振込 40万, PayPal 35万, PayPal 35万` |
   | 総額 | 空欄でOKです。「2回目以降の1回の金額」×回数（1回目の金額があれば足して）で計算します。どちらも空欄なら、料金マスタから入ります |
   | 1回目の金額・2回目以降の金額 | 空欄なら均等に割ります（割り切れない端数は1回目に足します）。頭金がある場合は1回目に入れます |
   | 決済リンク | スクエア・moshのリンクを入れます。PayPalは空欄なら `paypal.me/crozentokyo/金額jpy` を自動で作ります。併用でカードが2枚なら、改行かスペースで区切って2つ入れます |
   | 個別コンサルスタート月 | 空欄の場合、新規・個別ありなら「契約日の翌月〜」、個別なしなら「ー」、更新・個別ありなら空欄になります |
   | 今回だけの金額 | 特別価格のときにチェックします。料金マスタに登録されなくなります |
   | 覚書の日付（一番右の列） | 覚書の署名欄の上に入る日付（＝メールと覚書を送る日）です。空欄なら**手続き期限の5日前**（すでに過ぎていれば処理した日）になります。違う日に送るときだけ入力します。何日前にするかは「設定」の「覚書の日付_期限の何日前」で変えられます |

2. **全部入力し終わってから**「処理する」にチェックを入れます
3. 「【本番モード】〇件を処理します」という確認画面が出るので「はい」を押します（「いいえ」ならチェックが外れて何も起きません）
   - チェックを入れても動かない時は、メニュー「プラチナ管理 → ✅ チェックした契約を処理する」を押してください（その時に仕組みが自動で設定されます）
4. Gmail の下書きを確認して送信します。分割の方は「覚書PDF」をGMOサインにアップロードします

途中でエラーになった場合は、「状態」列に理由が表示され、チェックが外れます。直してからもう一度チェックを入れると、**終わっていない手順だけ**を実行します（「完了した手順」列を見て判断します）。

### 覚書を作り直したいとき
雛形を直したときなどは、「契約入力」で作り直したい方の行を選んで、メニュー「🔁 選択した行の覚書を作り直す」を押します。古い覚書とPDFはゴミ箱に入り、新しいものが作られます（メンバーリストなど、ほかのシートには触りません）。

### 入金を確認したとき
「支払予定」シートの「入金済」にチェックを付けます。チェックが付いた支払いは通知されません。

### 料金表
初めての組み合わせ（新規/更新 × 個別 × 回数 × 支払方法）で処理すると、「料金マスタ」に自動で追加されます。次に同じ組み合わせを選ぶと、総額・金額・リンクが自動で入ります。手で直しても大丈夫です。

## メール文面・覚書を直したいとき

「テンプレート」フォルダのドキュメントを直接編集します。スクリプトを触る必要はありません。

- メールの**1行目は `件名：…`** にしてください。その下が本文になります
- `{{氏名}}` のような目印が、実際の内容に置き換わります
- **目印だけが書かれた行の中身が空のとき**（銀行振込ではない方の `{{振込口座}}` など）は、その行ごと消えます

| 目印 | 中身の例 |
|---|---|
| `{{氏名}}` | 山田花子 |
| `{{期限}}` | 6月26日（金） |
| `{{合計金額}}` | 1,420,000円 |
| `{{支払内容}}` | 銀行振込の一括払い ／ 1回46,000円の12分割 ／ 銀行振込40万円＋クレジットカード35万円×2枚の一括払い |
| `{{支払方法名}}` | 銀行振込 ／ クレジットカード |
| `{{分割回数}}` | 12 |
| `{{1回金額}}` | 46,000円 |
| `{{1回目金額}}` | 46,000円 |
| `{{振込口座}}` | 振込口座とご入金額のまとまり（銀行振込があるときだけ） |
| `{{決済リンク}}` | 「決済リンクはこちら＞＞」とURL（カードが2枚なら1枚目・2枚目に分けて表示） |
| `{{分割補足}}` | ※2回目のお支払いは半年後となります（2分割で半年ごとのときだけ） |
| `{{フォームURL}}` | 個別あり/なし × 一括/分割 に合った受講規約フォーム |
| `{{プログラム名}}` | プラチナプログラム ／ プラチナ継続プログラム |

支払い案内メールで使える目印：`{{氏名}}` `{{回}}` `{{支払期日}}` `{{支払金額}}` `{{振込口座}}` `{{決済リンク}}`

覚書の雛形で使える目印：`{{氏名}}` `{{プログラム名}}` `{{合計金額}}` `{{分割回数}}` `{{作成日}}`（「覚書の日付」。空欄なら手続き期限の5日前）、`{{支払明細}}`（「2026年6月23日までに、710,000円」が回数分並びます）

## 設定シートの主な項目

| 項目 | 内容 |
|---|---|
| 通知_何日前 | 初期値は14です |
| 通知_対象 | `2分割のみ`（初期値）／`銀行振込すべて`／`すべて`。どれも2回目以降の支払いが対象です |
| 通知_時刻 | 変えたら「初期設定」をもう一度押してください |
| フォーム_… | 受講規約フォームのURL |
| 振込口座 | メールに入る口座情報 |

## 開発者向け

計算や文面の組み立てなど、Googleのサービスを使わない部分のテストは次のコマンドで実行できます。

```
TZ=Asia/Tokyo node platinum/test/run.js
```
