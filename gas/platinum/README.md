# プラチナプログラム 自動化

Shine A Light のプラチナプログラム（上位クラス）向けの自動化です。
Shine A Light 本体とは **別のスプレッドシート・別のGASプロジェクト**で運用します。

理由：

- 期のサイクルが違う（本体は3〜4ヶ月で期が変わる／プラチナは継続型）
- 受講生が違うので名簿が別。宛先の取り違えは事故になる
- 片方を壊してももう片方は動き続ける

共通コードは1本のままです。`PROFILES` に `masterSpreadsheetId` を足せば、
プロファイルごとに参照するマスタを切り替えられます。

## マスタスプレッドシート

`プラチナプログラム_自動化マスタ.xlsx` を Google スプレッドシートとしてアップロードして使います。

| シート | 役割 |
|---|---|
| 使い方 | 凡例と運用の流れ |
| 基本設定 | Zoom・フォームURL・Chatwork・署名・合宿予定・実行時刻 |
| スケジュール | プラチナグルコンの日程（1行1件） |
| メールテンプレート | 3日前／前日／当日／アーカイブ の4通 |
| 受講生名簿 | 氏名・メールアドレス・在籍状況 |
| 個別コンサル管理 | 月1回の個別コンサルの予約案内とリマインド |
| 差込項目一覧 | `{{...}}` の一覧（参照用） |

## 自動化の流れ（プラチナグルコン）

| いつ | 何をするか |
|---|---|
| 5日前 朝 | 「3日前」「前日」「当日」の下書きを3通作成 → Chatwork通知 |
| 5日前 | 事前フォームを自動オープン |
| 前日 13:00 | 事前フォームを自動クローズ |
| 前日 13:30 | 活動報告まとめドキュメントを作成 → Chatwork通知<br>同時にスケジュールの「活動報告まとめURL」へ書き戻し |
| アーカイブ | 「アーカイブ動画URL」が入力されたら、アーカイブメールの下書きを作成 |

**下書きに宛先は入りません。** 送信予約のときに手動で入れる運用です。

## 差込項目

`{{日程}}` `{{日程短}}` `{{時間帯}}` `{{開始時}}` `{{提出期限}}` `{{提出期限短}}`
`{{zoomリンク}}` `{{ミーティングID}}` `{{事前フォームURL}}` `{{署名}}` `{{合宿予定}}`
`{{アーカイブ動画URL}}` `{{活動報告まとめURL}}` `{{今後の日程}}`

`{{今後の日程}}` はスケジュールから自動生成します（今日以降の回を月ごとに整形）。
開始時刻が12時より前のときだけ「午前」が付きます。
