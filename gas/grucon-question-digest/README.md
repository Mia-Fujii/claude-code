# グルコン事前質問まとめ 自動化（GAS）

Googleフォームに集まったグルコンの事前質問を、自動でGoogleドキュメントにまとめ、
前日13:30にChatworkへ通知します。

## やっていること

| いつ | 何をするか |
|---|---|
| グルコン **5日前** | Googleフォームを自動でオープン |
| **5日前 00:00 〜 前日 13:00** | この期間の回答だけを収録対象にする |
| **前日 13:00** | フォームを自動でクローズ |
| **前日 13:30** | ドキュメントを作成し、Chatworkへリンクを送信 |

- 同一人物の判定は **メールアドレス**（正規化して比較）。空欄のときは **お名前** で補完します。
- **まったく同じ内容**の質問が複数あれば1件に統合します（誤って2回送信したケース）。
- 内容が違う質問は統合せず、同じ方の下に「**追記：**」として続けます。
- 何を統合したかは **Chatworkのメッセージに補足として記載**されます。

## 保存先

```
Shine A Light講座 / {期} / グルコン / 8/20グルコン
```

`{期}` は **マスタスプレッドシート「基本設定」シートの B2セル**（例: `21期`）をそのまま使います。
**期が変わったら B2 を書き換えるだけ**で、保存先フォルダが自動で切り替わります。

フォルダが存在しない場合は自動で作成し、Chatworkの通知に
「フォルダを新規作成しました」と明記されるので、期の書き換え忘れにすぐ気づけます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| **`ALL-IN-ONE.gs`** | **全部を1つにまとめたもの。これ1本を貼り付ければ動きます** |
| `Config.gs` | 設定（ID・時刻・書式など）。**基本ここだけ触ります** |
| `Schedule.gs` | マスタスプレッドシートから期とグルコン日程を読む |
| `Responses.gs` | 回答の読み取り・名寄せ・重複統合 |
| `Document.gs` | Googleドキュメントの生成 |
| `FormControl.gs` | フォームの自動開閉 |
| `Chatwork.gs` | Chatwork通知 |
| `Main.gs` | トリガー管理・エントリポイント・手動実行用の関数 |
| `Menu.gs` | スプレッドシート上のメニュー |
| `SetupForm.gs` | 初回セットアップ（フォーム作成・認証情報の保存） |
| `Test.gs` | テスト用（サンプル作成・接続確認） |
| `Util.gs` | 共通処理（日付・文字列の正規化など） |

## セットアップ手順

### 1. コードを貼り付ける

**フォームの回答スプレッドシート**を開き、
**拡張機能 → Apps Script** を選びます。

1. 左の `コード.gs` の中身を全部消して、**`ALL-IN-ONE.gs` を丸ごと貼り付け**
2. `⌘S` / `Ctrl+S` で保存
3. **スプレッドシートに戻って再読み込み**（F5）
4. 上部に **「グルコン質問まとめ」メニュー**が現れます

> 回答スプレッドシートは期が変わっても同じものを使い続けるので、
> ここに貼って問題ありません。期ごとに変わるのはマスタスプレッドシートだけで、
> そちらはIDで参照しています。

**タイムゾーンの確認（重要）**

Apps Script の画面左 **⚙️ プロジェクトの設定** → タイムゾーンが
**「(GMT+09:00) 日本標準時」** になっているか確認してください。
ここがズレると日付の判定が1日ずれます。

### 2. メニューから動かしてみる

| メニュー | 内容 |
|---|---|
| **① 設定状況を確認** | 期・フォルダ・グルコン日程が正しく読めているか確認 |
| **② テスト：この回答シート全部でドキュメント作成** | 回答シートの**全行**からドキュメントを1本作る |

初回は Google の認証画面が出ます。
「詳細」→「（安全ではないページ）に移動」→「許可」で進みます（自分で書いたスクリプトなので正常です）。

②を実行すると `Shine A Light講座 / {期} / グルコン` に
**`(テスト)◯/◯グルコン`** が1本でき、Chatworkへ送られるはずの文面もダイアログに出ます（**送信はされません**）。

ここで確認するポイント：

- 保存先フォルダが正しいか（違っていれば「基本設定」B2を直す）
- お名前の大きさ・黄色背景が好みか（`Config.gs` の `DOC` で調整）
- 「追記：」のまとめ方、重複統合の補足文が意図通りか

> ⚠️ ②は**日付の絞り込みを無視**します。本番は「グルコン日の5日前00:00〜前日13:00」の
> 回答だけが対象です。テスト中は日程とタイムスタンプが噛み合わず1件も残らないことが
> 多いため、テスト専用にこうしています。

フォームがまだ無い状態で書式だけ見たい場合は、スクリプトエディタから
`demoBuildSampleDocument` を実行すると、組み込みのサンプル質問で1本作れます。

### 3. Googleフォームを用意する

**新しく作る場合**（formzuからの移行）

エディタで `setupCreateForm` を選んで実行します。以下がまとめて作られます。

- フォーム「グルコン事前質問フォーム」（お名前 / ご質問&ご相談）
- 回答スプレッドシート
- スクリプトプロパティへのID登録

実行後、ログに出るURLを控えてください。

**フォームで手動設定が必要な項目（重要）**

| 設定場所 | 設定値 | 理由 |
|---|---|---|
| 設定 → 回答 → メールアドレスを収集する | **回答者からの入力** | 「確認済み」にするとGoogleアカウントが必須になり、回答できない方が出ます |
| 設定 → 回答 → 回答のコピーを回答者に送信 | 常に表示 | formzuの自動返信メールの代わり（APIから設定できないため手動） |

**すでにフォームを作ってある場合**

`SetupForm.gs` の `setFormIds()` にIDを書いて実行します。

### 4. Chatworkの認証情報を登録する

`SetupForm.gs` の `setChatworkCredentials()` にAPIトークンを入れて実行します。
**実行後、コードからトークンを消してください**（スクリプトプロパティに保存済みになります）。

手動で登録する場合は「プロジェクトの設定 → スクリプト プロパティ」に以下を追加します。

| プロパティ名 | 値 |
|---|---|
| `CHATWORK_TOKEN` | Chatwork APIトークン |
| `CHATWORK_ROOM_ID` | `444552021` |

### 5. 設定を確認する

`showStatus` を実行すると、現在の設定状況がログに出ます。

```
期（基本設定B2）      : 21期
フォームID            : 1AbC...
フォームの状態        : 締切中
講座ルート直下フォルダ: 21期 / 20期 / 19期
グルコン件数          : 6件
次回グルコン          : 9/15（火） 10:00〜11:00
　受付期間            : 9/10 00:00 〜 9/14 13:00
　ドキュメント名      : 9/15グルコン
```

**ここで「講座ルート直下フォルダ」に期のフォルダ名が正しく並んでいるか**、
**「期（基本設定B2）」がその命名と一致しているか**を必ず確認してください。

### 6. 動作テストをする

`manualBuildPreview` を実行します。
**Chatworkには送信せず**、ドキュメントだけを作ってログにURLと送信予定のメッセージを出します。

問題なければ `manualBuildAndNotify` で実際にChatworkまで流して確認します。
（`Config.gs` の `DRY_RUN: true` にすると、Chatwork送信をログ出力だけに差し替えられます）

### 7. トリガーを設置する

メニューの **「自動実行トリガーを設置」** を1回だけ実行します（または `setupInstallTriggers`）。
以下の2つが設置されます。

| 関数 | 時刻 | 役割 |
|---|---|---|
| `dailyPlanner` | 毎日 6:00 | フォームのオープン判定／当日の単発トリガー設置 |
| `dailySafetyNet` | 毎日 15:00 | 13:00・13:30の処理が落ちていた場合の救済 |

13:00（締切）と13:30（送信）は、**当日の朝に単発トリガーとして仕込まれます**。
GASの定期トリガーは指定時刻から±15分ほどずれるため、締切が早まらないようにこの方式にしています。

### 8. 案内メールのURLを差し替える

マスタスプレッドシート「基本設定」の **「グルコン事前フォームURL」** を、
新しいGoogleフォームの回答用URLに貼り替えてください。

## 期が変わったときの作業

1. マスタスプレッドシートを **コピー**（上書きしない：前期の記録が残ります）
2. 新ファイルの「基本設定」 **B2 を `21期` に書き換える**
3. 「スケジュール」に21期の日程を入れる
4. GASのスクリプトプロパティ `MASTER_SPREADSHEET_ID` に新ファイルのIDを設定
   （または `Config.gs` の `MASTER_SPREADSHEET_ID` を書き換え）
5. `showStatus` を実行して確認

トリガーの作り直しは不要です。

## 手動で実行できる関数

| 関数 | 用途 |
|---|---|
| `showStatus` | 設定状況・次回グルコン・受付期間を確認する |
| `manualBuildPreview` | ドキュメントだけ作る（Chatwork送信なし） |
| `manualBuildAndNotify` | ドキュメントを作ってChatworkへ送る |
| `manualOpenForm` / `manualCloseForm` | フォームを手動で開閉する |
| `demoBuildSampleDocument` | **フォーム不要**。組み込みのサンプル質問でドキュメントを1本作る |
| `testBuildFromAllRows` | **実際の回答シートの全行**でドキュメントを作る（日付の絞り込みなし） |
| `manualBuildPreviewForDate` | 日付を指定して作る（例: `'2026/8/20'`）。Chatwork送信なし |
| `testChatworkConnection` | Chatworkへの接続確認（テスト投稿を1件送ります） |
| `setupInstallTriggers` | トリガーを設置し直す |
| `removeAllTriggers` | トリガーを全部消す |

同じ日に何度実行しても、**同名のドキュメントは作り直されるだけ**でファイルは増えません。

## 調整できる設定（`Config.gs`）

| 設定 | 既定値 | 説明 |
|---|---|---|
| `OPEN_DAYS_BEFORE` | `5` | フォームを開く日（何日前か） |
| `CLOSE_HOUR` / `CLOSE_MINUTE` | `13` / `0` | 締切時刻 |
| `NOTIFY_HOUR` / `NOTIFY_MINUTE` | `13` / `30` | Chatwork送信時刻 |
| `MERGE_BY_NAME` | `true` | メアドが違ってもお名前が同じなら統合する |
| `DOC.NAME_FONT_SIZE` | `14` | お名前の文字サイズ |
| `DOC.BODY_FONT_SIZE` | `11` | 本文の文字サイズ |
| `DOC.NAME_HIGHLIGHT` | `#FFE599` | お名前の背景色 |
| `DOC.ADDENDUM_LABEL` | `追記：` | 2件目以降の見出し |
| `DOC.BLANK_LINES_BETWEEN_PEOPLE` | `2` | 次のお名前の手前に入れる空行の数 |
| `DOC.BLANK_LINES_BEFORE_ADDENDUM` | `1` | 「追記：」の手前に入れる空行の数 |
| `DOC.INCLUDE_NOTES` | `false` | 自動処理メモをドキュメントにも入れるか |
| `DOC.SHARE_ANYONE_WITH_LINK` | `true` | 「リンクを知っている全員が閲覧可」に自動設定するか |
| `DRY_RUN` | `false` | `true` でChatwork送信をログ出力だけにする |

## 仕様メモ

- **対象は「グルコン」のみ**。日程シートの `内容` 列が `グルコン` と**完全一致**する行だけを拾います。
  「サポート講師ビギナーグルコン」は対象外です（別フォームを用意すれば同じ仕組みで動かせます）。
- **重複判定**は、改行・空白・全角半角の違いだけを吸収した**完全一致**です。
  言い回しが少しでも違えば別の質問として残ります。
- 回答スプレッドシートは期をまたいで蓄積されますが、**日付で期間を絞る**ため影響ありません。
- 質問が空欄の回答（欠席連絡のみなど）はドキュメントに載りません。
- 本文中のURLは自動でリンクになります。
- ドキュメントは作成時に **「リンクを知っている全員が閲覧可」** に自動設定されます
  （`DOC.SHARE_ANYONE_WITH_LINK`）。Chatworkのリンクからそのまま開けます。
  組織のポリシーで外部共有が禁止されている場合は設定に失敗しますが、処理は止まらず、
  Chatworkの通知に「⚠ 共有設定の変更に失敗」と出ます。
  自動設定をやめてフォルダの共有設定を引き継ぎたい場合は `false` にしてください。
- エラーが起きた場合は、Chatworkにエラー内容が通知されます。
