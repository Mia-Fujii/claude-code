# プラチナグルコン メール下書き 自動作成

**プラチナグルコン日程** スプレッドシートに貼り付けて使う、**メール下書き専用**のGASです。

質問まとめ・フォームの開閉は、**プラチナグルコン質問受付フォーム（回答）** 側の
GAS（`gas/grucon-question-digest`）が担当します。**役割を分けているので二重に動きません。**

## やること

| いつ | 何をするか |
|---|---|
| 「メールセット」列の日付の朝（7:00） | 「3日前」「前日」「当日」の**3通を下書き作成** → Chatworkに通知 |
| 「アーカイブ動画URL」を入力した翌朝 | アーカイブメールを下書き作成 → Chatworkに通知 |

- **宛先は空**です。送信予約のときに手動で入れてください
- **送信はしません**。下書きまでです
- 下書きは**スクリプトを動かしているアカウント**のGmailに入ります
  （`shinealightonlineschool@gmail.com` でログインして設定してください）
- 同じ回の下書きは**二重に作りません**（「下書き作成」列で記録）

### 本文中のリンクについて

既定（`CONFIG.HTML_BODY: true`）では、**URLが実際のリンクになった状態**で下書きを作ります。
改行・空行はそのまま保たれるので、見た目はテキストメールと変わりません。

プレーンテキストのみにしたい場合は `false` にしてください
（その場合、リンクにするかは受信側のメールソフト任せになります）。

```javascript
HTML_BODY: false,
```

## 使える差込項目

| 差込 | 入る内容 | どこから |
|---|---|---|
| `{{日程}}` | 10月6日（火） | スケジュール |
| `{{日程短}}` | 10/6（火） | スケジュール |
| `{{提出期限}}` | 10月5日（月） | 前日（自動計算） |
| `{{提出期限短}}` | 10/5(月) | 前日（自動計算） |
| `{{時間帯}}` | 10時〜11時 | スケジュール |
| `{{開始時}}` | 10時 | スケジュール |
| `{{zoomリンク}}` | | 基本設定 |
| `{{ミーティングID}}` | | 基本設定（「ミーティングID: 」が付いていても大丈夫） |
| `{{事前フォームURL}}` | | 基本設定 |
| `{{合宿予定}}` | | 基本設定（改行もそのまま） |
| `{{アーカイブ動画URL}}` | | スケジュール（手入力） |
| `{{活動報告まとめURL}}` | | スケジュール（質問まとめ側のGASが自動で書き戻し） |
| `{{今後の日程}}` | 下記 | スケジュールから自動生成 |

`{{今後の日程}}` は、その回より**後**の予定を1行1件で並べ、**月が変わるところで1行あけます**。

```
10月27日（火）21時〜22時

11月10日（火）10時〜11時
11月24日（火）21時〜22時

12月1日（火）21時〜22時
12月15日（火）10時〜11時
```

## セットアップ

1. **プラチナグルコン日程** を開く → 拡張機能 → Apps Script
2. `コード.gs` を全消しして `MAIL-DRAFT-ONLY.gs` を貼り付け → 保存
3. `setChatworkCredentials` にトークンを入れて実行 → **コードからトークンを消す**
4. スプレッドシートを再読み込み →「メール下書き」メニューが出る
5. メニュー →「**① 設定状況を確認**」
   - 実行アカウントが `shinealightonlineschool@gmail.com` か
   - 基本設定から値が読めているか
6. メニュー →「**② メールテンプレートを初期設定**」
   - 「メールテンプレート」シートが作られ、雛形4通が入ります
   - 「スケジュール」に `アーカイブ動画URL` `活動報告まとめURL` `下書き作成` の3列が増えます
7. メニュー →「**差し込みプレビュー**」で4通の中身を確認
8. メニュー →「**自動実行トリガーを設置**」

**文言の修正は「メールテンプレート」シート側で**行ってください（コードを触る必要はありません）。

## メニュー

| メニュー | 内容 |
|---|---|
| ① 設定状況を確認 | 実行アカウント・基本設定の値・次回の日程・トリガー |
| ② メールテンプレートを初期設定 | シートと列を自動作成（何度押しても上書きしません） |
| 差し込みプレビュー（下書きなし） | 4通の中身をダイアログで確認 |
| 事前案内3通の下書きを今すぐ作る | 次回分をGmailに作成 |
| アーカイブメールの下書きを作る | 動画URLが入っている直近の回 |
| Chatworkへの接続テスト | テスト投稿を1件 |
| 自動実行トリガーを設置 | 毎朝7:00の判定を有効化 |
| 本日分の処理に追いつかせる | 朝7時より後に設置したときの復旧 |
